# NillyQuickSnap — Ultra-Light Snipping Tool Replacement (46,5 KB!)

> **Πανάλαφρος, 100% Native Windows 10/11 αντικαταστάτης του Windows Snipping Tool (`585,8 MB` → `46,5 KB` — ~12.900× μικρότερο!) με ~2–5 MB idle RAM στο System Tray.**

## Χρήση & Συντομεύσεις
- **`Ctrl + Alt + S`** ή **1 κλικ στο εικονίδιο στο System Tray**. Το **`Print Screen`** λειτουργεί όταν το πλήκτρο είναι διαθέσιμο στο NillyQuickSnap. Το **`Win + Shift + S`** ακολουθεί την υπάρχουσα ρύθμιση των Windows.
- **Σύρε & Άφησε:** Αντιγράφει αμέσως στο Clipboard (`Ctrl+V`) **ΚΑΙ** αποθηκεύει αυτόματα PNG στον φάκελο `Εικόνες\Στιγμιότυπα οθόνης` (`Screenshot yyyy-MM-dd HHmmss.png`)!
- **Κράτα `Shift` όταν αφήνεις** *(ή `Ctrl + Alt + Shift + S`)*: Ανοίγει τη μπάρα σχεδίασης (**`A`** Βέλος, **`R`** Πλαίσιο, **`P`** Στυλό, **`H`** Marker, **`B`** Privacy Blur, 5 χρώματα, `Ctrl+Z` Undo, `Enter` OK/Copy+Save, `Ctrl+S` Save As).
- **`F`** = Ολόκληρη Οθόνη · **`Esc`** / Δεξί κλικ = Ακύρωση.

## Εγκατάσταση (Zero Admin · Portable)
Τρέξε με διπλό κλικ το **`Install_NillyQuickSnap.bat`** — μεταγλωττίζει το `NillyQuickSnap.exe`, το προσθέτει στην αυτόματη εκκίνηση και το ανοίγει στο System Tray. Οι ρυθμίσεις Print Screen και `ms-screenclip` μένουν στα Windows. Το `Uninstall_NillyQuickSnap.bat` αφαιρεί την εγγραφή εκκίνησης και τις συντομεύσεις του NillyQuickSnap.
